# בינה — ייעוץ ארגוני חברתי לציבור החרדי

אתר תדמית של פירמת הייעוץ "בינה".

## מבנה
- `index.html` — דף הבית (RTL, עברית)
- `styles.css` — עיצוב
- `script.js` — אינטראקציות (תפריט נייד, אנימציית גלילה, טופס יצירת קשר)

## הרצה מקומית
פתחו את `index.html` בדפדפן, או הריצו שרת סטטי:
```
npx serve .
```

## פריסה
האתר מתפרסם אוטומטית ל-GitHub Pages מענף `main`.
